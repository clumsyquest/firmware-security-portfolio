## What's inside

| Track | What I work through |
|---|---|
| **01 · Bare metal** | STM32 from scratch: GPIO blink, UART + interrupts, timers & PWM |
| **02 · C vulnerabilities** | Hands-on labs: buffer overflow, heap overflow, format string |
| **03 · ASM & reverse** | ARM assembly basics, calling conventions, C → ASM translation |
| **04 · Embedded Linux** | Custom Buildroot, Yocto BSP, U-Boot bootloader |
| **05 · Firmware dumping** | Router dump (TP-Link), STM32 flash read, UART sniffing |
| **06 · Hardware debug** | JTAG/SWD, probing, on-target debugging |
| **07 · Exploitation** | ROP chains, stack pivot, ARM shellcode |
| **08 · Security features** | Mitigations & hardening on embedded targets |
| **09 · Automation tools** | Scripts & tooling to speed up the workflow |
| **10 · Major projects** | Device audits: IP camera, smart plug, industrial controller |
| **11 · CVEs** | Findings, as the work goes deeper |
| **12 · Presentations** | Notes, write-ups, talks |

> These are **learning labs and personal projects**, documented honestly as I
